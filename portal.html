为什么你现在会看到 404？

你的截图显示 "There isn't a GitHub Pages site here"，说明这个仓库还没有成功启用 GitHub Pages 发布。

处理方法：进入仓库的 Settings → Pages，把 Branch 设为 main，目录设为 / (root)，保存后等待 1~3 分钟。
打开 Pages 设置 查看 Actions 发布状态 发布后访问主页
